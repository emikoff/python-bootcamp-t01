# Python Bootcamp T01 — алгоритмы и основы Python

Набор из десяти небольших программ на Python. Каждая программа решает отдельную задачу и запускается независимо. В проекте собраны примеры работы с числами и коллекциями, обхода матриц, динамического программирования, проверки данных и обработки JSON.

## Содержание

| Файл | Тема |
|---|---|
| `src/exercise1/task1.py` | Скалярное произведение векторов |
| `src/exercise2/task2.py` | Проверка числа на палиндром |
| `src/exercise3/task3.py` | Поиск и классификация фигур в матрице с помощью DFS |
| `src/exercise4/task4.py` | Построение треугольника Паскаля |
| `src/exercise5/task5.py` | Разбор десятичного числа и точное форматирование результата |
| `src/exercise6/task6.py` | Проверка JSON и объединение списков фильмов |
| `src/exercise7/task7.py` | Максимальная сумма пути по матрице |
| `src/exercise8/task8.py` | Подсчёт уникальных чисел |
| `src/exercise9/task9.py` | Вычисление производной многочлена в точке |
| `src/exercise10/task10.py` | Подбор пары устройств по году выпуска и времени работы |

## Требования

- Python 3.10 или новее;
- сторонние библиотеки для запуска решений не требуются.

## Запуск

Из корня репозитория запусти нужный файл, например:

```bash
python3 src/exercise1/task1.py
python3 src/exercise4/task4.py
python3 src/exercise8/task8.py
```

Программы с интерактивным вводом читают данные из стандартного ввода. Для упражнений 3 и 6 входной файл открывается относительно текущего каталога, поэтому запускай их из соответствующей папки:

```bash
cd src/exercise3
python3 task3.py
```

```bash
cd src/exercise6
python3 task6.py
```

## Структура

```text
src/
├── exercise1/   решение и входной код упражнения 1
├── ...
└── exercise10/  решение упражнения 10
```

В упражнениях 3 и 6 рядом с программами находятся `input.txt` с демонстрационными данными. Остальные программы получают данные через стандартный ввод.

## Проверка

Постоянные автоматизированные тесты пока не добавлены. Для проверки запускай каждую программу отдельно и подавай ей подходящие входные данные.
